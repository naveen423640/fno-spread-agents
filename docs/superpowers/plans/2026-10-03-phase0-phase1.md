> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the Phase 0 safety and verification work, then build the Phase 1 data foundation: a point-in-time NSE F&O data store in a new Python engine, a trading calendar, a dated universe, engine-side FYERS authentication, a local read-only API, and oracle parity with the existing TypeScript 6-month test's data layer.

**Architecture:** A new Python package `engine/` (DuckDB store, NSE archive client, calendar, universe, token store, incident log, read-only FastAPI) lives beside the existing TypeScript dashboard. The dashboard reads the engine only through server-side route handlers over `127.0.0.1`, and falls back visibly to the static list when the engine is down. The existing TypeScript backtest (`lib/backtest/nse-data.ts`) is the oracle for cycle discovery and universe ranking.

**Tech Stack:** Python 3.14 (wheels checked by dry-run), DuckDB 1.5.6, PyArrow 25.0.1, FastAPI 0.129.1, pytest 9.1.1; TypeScript, Vitest 5.0.2.

## Global Constraints

- Paper only. `EXECUTION_MODE=paper`, `LIVE_EXECUTION_ENABLED=false`. No order-placement code exists, and tests assert that no FYERS order endpoint is referenced or called.
- Never read or print `.env*` secrets or any token. The assistant never opens `.env*` or the token file; secrets stay in the user's environment and are never sent to an LLM.
- Every data record carries `effective_date`, `available_ts` and `retrieval_ts`. A decision may only read data whose `available_ts` is at or before its decision time.
- One ledger rule from the spec stays out of scope until Phase 3. No ledger, risk or broker code in these phases.
- Dashboard runs locally in Phases 1-4 and reads the engine through a **local read-only API** (localhost, GET only). Cloud deployment is deferred.
- FYERS is data only. Engine-side token: stored outside the repository and outside the browser, never written to the database, logs or LLM prompts, never sent to the dashboard. Missing/expired/rejected token blocks new entries and records one incident.
- The engine must reproduce the TypeScript cycle and universe logic; discrepancies are investigated and classified (engine bug / oracle bug / deliberate difference), not assumed.
- Replace the static 210-stock heat-map universe with a dated universe in Phase 1 (moved here from Phase 0 by decision).
- Anything not run against real data is reported as unverified.

## Decisions taken (confirm or change at plan approval)

1. **Cost rates:** Phase 0 *verifies* the cost constants in `lib/options-costs.ts` against official sources and records the result. Moving them to a dated config file moves to Phase 3 where costs are first used.
2. **Constants that depend on audits:** the bhavcopy publication time (`available_ts` rule), the ban-list URL and format, and the FYERS token lifetime are set from the Phase 0 audit. **Updated after Tasks 3 and 5:** the bhavcopy rule is now **22:30 IST** (measured `Last-Modified` 18:38 to 22:16 over 15 days; conservative, not a guarantee; see `docs/audit/01-nse-archives.md`). The ban-list file `fo_secban_DDMMYYYY.csv` is verified, and the file for trade date T is published the evening **before** T, so it must not use the bhavcopy rule. The token lifetime is documented as daily (unverified until the user runs the probe); the 8-hour default stays a conservative assumption. **Every test that depends on the publication time must compute it from `available_after()` and use `timedelta` arithmetic, never a hard-coded UTC time or `minute - 1`** (the literal `13:30` values in Tasks 8, 9 and 15 below are examples of the old 19:00 rule and must be replaced by `available_after(day)`).
3. **Engine environment:** `engine/.venv` on Python 3.14 (`py -3.14`). If any pinned wheel fails to install, fall back to `uv venv --python 3.13`; record the working versions in `engine/requirements.lock`.
4. **Token file:** under `%USERPROFILE%\.fno-engine\fyers_token.json` (path from `FNO_ENGINE_TOKEN_FILE`), refused if it resolves inside the repository. Windows ACLs are not enforced by the code; this is a stated limitation.
5. **Dashboard to engine link:** Next route handlers call `http://127.0.0.1:8765` server-side (env `FNO_ENGINE_URL`), so the browser never talks to the engine and no CORS is needed.
6. **Corporate actions:** ingested from a user-verified CSV at first; no scraping until the audit names a reliable source.
7. **Heat map header:** the "210-stock FYERS universe" subtitle becomes dynamic (`N-stock universe · source`). The Markov tab keeps the static list for now; it is a listed follow-up.
8. **Holiday list:** you verify `reference/nse_holidays.json` against the official NSE list; the engine refuses a calendar flagged `verified: false` for production runs.

## Review Focus

```ts
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join } from 'node:path';

import { describe, expect, it } from 'vitest';

const ALLOWED_FYERS_PATHS = new Set(['', '/api/v3/generate-authcode', '/api/v3/validate-authcode', '/data', '/data/history', '/data/quotes', '/data/options-chain-v3']);
const ALLOWED_DATA_SUFFIXES = new Set(['quotes', 'history', 'options-chain-v3']);
const DENY_TERMS = /place_?order|create_?order|cancel_?order|modify_?order|exit_?positions|multi_?order|convert_?position|\bgtt\b/i;
const SCAN_DIRS = ['app', 'lib', 'db', 'components', 'hooks'];

function sourceFiles(directory: string): string[] {
  return readdirSync(directory).flatMap((name) => {
    const path = join(directory, name);
    if (statSync(path).isDirectory()) return sourceFiles(path);
    return /\.(ts|tsx|mjs|js)$/.test(name) && !/\.test\.(ts|tsx)$/.test(name) ? [path] : [];
  });
}

export function findViolations(root: string): string[] {
  const violations: string[] = [];
  for (const dir of SCAN_DIRS) {
    let files: string[] = [];
    try { files = sourceFiles(join(root, dir)); } catch { continue; }
    for (const file of files) {
      const text = readFileSync(file, 'utf8');
      for (const match of text.matchAll(/https?:\/\/[a-z0-9.-]*fyers\.in(\/[A-Za-z0-9/_-]*)?/gi)) {
        if (!ALLOWED_FYERS_PATHS.has(match[1] ?? '')) violations.push(`${file}: FYERS path ${match[1]}`);
      }
      for (const match of text.matchAll(/FYERS_DATA_BASE\}\/([A-Za-z0-9_-]+)/g)) {
        if (!ALLOWED_DATA_SUFFIXES.has(match[1])) violations.push(`${file}: FYERS data suffix ${match[1]}`);
      }
      if (DENY_TERMS.test(text)) violations.push(`${file}: order-related term`);
    }
  }
  return violations;
}

describe('no FYERS order endpoints', () => {
  it('the application source references only allowed FYERS auth and data endpoints', () => {
    expect(findViolations(process.cwd())).toEqual([]);
  });

  it('the scanner itself catches an order endpoint (it can fail)', async () => {
```

```ts
export type ExecutionSettings = { executionMode: 'paper'; liveExecutionEnabled: false };

// Fail closed: only the exact strings "paper" and "false" are accepted; unset means the safe defaults.
export function readExecutionSettings(env: Record<string, string | undefined> = process.env): ExecutionSettings {
  const mode = env.EXECUTION_MODE ?? 'paper';

  if (mode !== 'paper') throw new Error(`EXECUTION_MODE must be "paper" (got "${mode}"). Live execution is disabled in this system.`);

  return { executionMode: 'paper', liveExecutionEnabled: false };
}

export function assertPaperOnly(): void {
```

```python
from __future__ import annotations

import os
from dataclasses import dataclass
from typing import Mapping


class LiveExecutionRefused(RuntimeError):
    pass


@dataclass(frozen=True)
class ExecutionSettings:
    execution_mode: str = "paper"
    live_execution_enabled: bool = False


def read_execution_settings(env: Mapping[str, str] | None = None) -> ExecutionSettings:
    env = os.environ if env is None else env
    mode = env.get("EXECUTION_MODE", "paper")
    live = env.get("LIVE_EXECUTION_ENABLED", "false")
    if mode != "paper":
        raise LiveExecutionRefused(f'EXECUTION_MODE must be "paper" (got "{mode}"). Live execution is disabled in this system.')
    if live != "false":
        raise LiveExecutionRefused('LIVE_EXECUTION_ENABLED must be "false". Live execution is disabled in this system.')
    return ExecutionSettings()


def assert_paper_only(env: Mapping[str, str] | None = None) -> None:
    read_execution_settings(env)
```

```python
from __future__ import annotations

from datetime import date, datetime, time, timezone
from zoneinfo import ZoneInfo

IST = ZoneInfo("Asia/Kolkata")

# Conservative assumption until the Phase 0 audit records the real publication time of the bhavcopy.
BHAVCOPY_PUBLISHED_AFTER = time(19, 0)


def require_aware(value: datetime) -> datetime:
    if value.tzinfo is None:
        raise ValueError("A timezone-aware datetime is required.")
    return value


def ist_datetime(day: date, at: time) -> datetime:
    return datetime.combine(day, at, tzinfo=IST)


def to_utc_naive(value: datetime) -> datetime:
    return require_aware(value).astimezone(timezone.utc).replace(tzinfo=None)


def from_utc_naive(value: datetime) -> datetime:
    return value.replace(tzinfo=timezone.utc)


def available_after(effective: date) -> datetime:
    """When data for this trading date may be treated as published (UTC-aware)."""
    return ist_datetime(effective, BHAVCOPY_PUBLISHED_AFTER).astimezone(timezone.utc)
```

```python
    buffer = io.StringIO()
```

```python
    writer.writerow(header)
```

```python
from __future__ import annotations

import csv
import io
import math
import zipfile

from .rows import CmRow, FoRow


class ArchiveFormatError(ValueError):
    pass


def _number(value: str | None) -> float:
    try:
        parsed = float(value) if value not in (None, "") else 0.0
    except ValueError:
        return 0.0
    return parsed if math.isfinite(parsed) else 0.0


def _read_csv(data: bytes, label: str) -> tuple[list[str], list[list[str]]]:
    try:
        with zipfile.ZipFile(io.BytesIO(data)) as archive:
            name = next((n for n in archive.namelist() if n.lower().endswith(".csv")), None)
            if name is None:
                raise ArchiveFormatError(f"NSE {label} archive did not contain a CSV file.")
            text = archive.read(name).decode("utf-8-sig")
    except zipfile.BadZipFile as error:
        raise ArchiveFormatError(f"NSE {label} archive is not a valid zip file.") from error
    rows = [row for row in csv.reader(io.StringIO(text)) if row]
    if len(rows) < 2:
        raise ArchiveFormatError(f"NSE {label} CSV is empty.")
    return rows[0], rows[1:]


FO_REQUIRED = ["TradDt", "FinInstrmTp", "TckrSymb", "XpryDt", "StrkPric", "OptnTp", "FinInstrmNm", "PrvsClsgPric", "UndrlygPric",
               "OpnPric", "HghPric", "LwPric", "ClsPric", "TtlTradgVol", "TtlTrfVal", "NewBrdLotQty", "OpnIntrst", "ChngInOpnIntrst"]


def parse_fo_bhavcopy_zip(data: bytes) -> list[FoRow]:
    header, body = _read_csv(data, "F&O")
    index = {name: i for i, name in enumerate(header)}
    for column in FO_REQUIRED:
        if column not in index:
            raise ArchiveFormatError(f"NSE F&O CSV is missing {column}.")
    settle = index.get("SttlmPric")
    rows: list[FoRow] = []
    for cells in body:
        if len(cells) < len(header) - 2:
            continue

        def at(name: str) -> str:
            return cells[index[name]] if index[name] < len(cells) else ""

        option_type = at("OptnTp")
        rows.append(FoRow(
            trading_date=at("TradDt"), instrument_type=at("FinInstrmTp"), ticker=at("TckrSymb"), expiry_date=at("XpryDt"),
            strike=_number(at("StrkPric")), option_type=option_type if option_type in ("CE", "PE") else "",
            instrument_name=at("FinInstrmNm"), open=_number(at("OpnPric")), high=_number(at("HghPric")), low=_number(at("LwPric")),
            close=_number(at("ClsPric")), previous_close=_number(at("PrvsClsgPric")), underlying_price=_number(at("UndrlygPric")),
            settle_price=_number(cells[settle]) if settle is not None and settle < len(cells) else 0.0,
            traded_volume=_number(at("TtlTradgVol")), traded_value=_number(at("TtlTrfVal")), lot_size=int(_number(at("NewBrdLotQty"))),
            open_interest=_number(at("OpnIntrst")), change_in_open_interest=_number(at("ChngInOpnIntrst")),
        ))
    if not rows:
        raise ArchiveFormatError("NSE F&O CSV had no usable rows.")
    return rows


def parse_cm_bhavcopy_zip(data: bytes) -> list[CmRow]:
    header, body = _read_csv(data, "cash")
    modern = "TckrSymb" in header
    names = {"ticker": ("TckrSymb", "SYMBOL"), "series": ("SctySrs", "SERIES"), "open": ("OpnPric", "OPEN"), "high": ("HghPric", "HIGH"),
             "low": ("LwPric", "LOW"), "close": ("ClsPric", "CLOSE"), "previous_close": ("PrvsClsgPric", "PREVCLOSE"),
             "traded_volume": ("TtlTradgVol", "TOTTRDQTY"), "traded_value": ("TtlTrfVal", "TOTTRDVAL")}
    index = {}
    for key, (new, old) in names.items():
        column = new if modern else old
        if column not in header:
            raise ArchiveFormatError(f"NSE cash CSV is missing {column}.")
        index[key] = header.index(column)
    rows = []
    for cells in body:
        if len(cells) <= max(index.values()) or not cells[index["ticker"]]:
            continue
        rows.append(CmRow(ticker=cells[index["ticker"]], series=cells[index["series"]], open=_number(cells[index["open"]]),
                          high=_number(cells[index["high"]]), low=_number(cells[index["low"]]), close=_number(cells[index["close"]]),
                          previous_close=_number(cells[index["previous_close"]]), traded_volume=_number(cells[index["traded_volume"]]),
                          traded_value=_number(cells[index["traded_value"]])))
    return rows
```

```python
from __future__ import annotations

import hashlib
import json
import time
import urllib.error
import urllib.request
from dataclasses import dataclass
from datetime import date, datetime, timezone
from pathlib import Path
from typing import Callable, Mapping

from ..ist import available_after
from .parsers import parse_fo_bhavcopy_zip
from .rows import FoRow

HEADERS = {"Accept": "application/zip,*/*", "Referer": "https://www.nseindia.com/", "User-Agent": "Mozilla/5.0 (compatible; FNOEnginePhase1/1.0)"}
FO_URL = "https://nsearchives.nseindia.com/content/fo/BhavCopy_NSE_FO_0_0_0_{stamp}_F_0000.csv.zip"
TRANSIENT = {429, 502, 503, 504}


class ArchiveError(RuntimeError):
    pass


@dataclass(frozen=True)
class HttpResult:
    status: int
    body: bytes


Transport = Callable[[str, Mapping[str, str]], HttpResult]


def urllib_transport(url: str, headers: Mapping[str, str]) -> HttpResult:
    request = urllib.request.Request(url, headers=dict(headers))
    try:
        with urllib.request.urlopen(request, timeout=60) as response:
            return HttpResult(response.status, response.read())
    except urllib.error.HTTPError as error:
        return HttpResult(error.code, b"")


@dataclass(frozen=True)
class FetchedReport:
    effective_date: date
    rows: list[FoRow]
    sha256: str
    size_bytes: int
    retrieved_at: datetime
    available_at: datetime
    source_url: str
    from_cache: bool


def _utc_now() -> datetime:
    return datetime.now(timezone.utc)


class NseArchiveClient:
    def __init__(self, cache_dir: Path, transport: Transport = urllib_transport, sleep: Callable[[float], None] = time.sleep, clock: Callable[[], datetime] = _utc_now):
        self.cache_dir = Path(cache_dir)
        self.transport = transport
        self.sleep = sleep
        self.clock = clock

    @staticmethod
    def fo_url(day: date) -> str:
        return FO_URL.format(stamp=day.strftime("%Y%m%d"))

    def _paths(self, day: date) -> tuple[Path, Path]:
        stamp = day.strftime("%Y%m%d")
        return self.cache_dir / "fo" / f"{stamp}.zip", self.cache_dir / "fo" / f"{stamp}.json"

    def _download(self, url: str) -> HttpResult:
        result = self.transport(url, HEADERS)
        for attempt in range(1, 3):
            if result.status not in TRANSIENT:
                return result
            self.sleep(0.25 * attempt)
            result = self.transport(url, HEADERS)
        return result

    def fetch_fo(self, day: date) -> FetchedReport | None:
        if day.weekday() >= 5:
            return None
        zip_path, meta_path = self._paths(day)
        url = self.fo_url(day)
        if zip_path.exists() and meta_path.exists():
            meta = json.loads(meta_path.read_text(encoding="utf-8"))
            body = zip_path.read_bytes()
            return self._report(day, body, datetime.fromisoformat(meta["retrieved_at"]), url, True)
        result = self._download(url)
        if result.status == 404:
            return None
        if result.status != 200:
            raise ArchiveError(f"NSE F&O archive returned HTTP {result.status} for {day.isoformat()}.")
        retrieved_at = self.clock()
        report = self._report(day, result.body, retrieved_at, url, False)  # parse first: a corrupt file is never cached
        zip_path.parent.mkdir(parents=True, exist_ok=True)
        zip_path.write_bytes(result.body)
        meta_path.write_text(json.dumps({"retrieved_at": retrieved_at.isoformat(), "sha256": report.sha256, "source_url": url}), encoding="utf-8")
        return report

    def _report(self, day: date, body: bytes, retrieved_at: datetime, url: str, from_cache: bool) -> FetchedReport:
        return FetchedReport(effective_date=day, rows=parse_fo_bhavcopy_zip(body), sha256=hashlib.sha256(body).hexdigest(), size_bytes=len(body),
                             retrieved_at=retrieved_at, available_at=available_after(day), source_url=url, from_cache=from_cache)
```

```python
from __future__ import annotations

import hashlib
import json
from datetime import date, datetime
from pathlib import Path

import duckdb
import pyarrow as pa

from ..ist import to_utc_naive
from ..nse.rows import FoRow
from .schema import STATEMENTS

FO_COLUMNS = ["row_number", "trading_date", "instrument_type", "ticker", "expiry_date", "strike", "option_type", "instrument_name", "open", "high",
              "low", "close", "previous_close", "underlying_price", "settle_price", "traded_volume", "traded_value", "lot_size", "open_interest", "change_in_open_interest"]


class Store:
    def __init__(self, path: Path | str):
        self.path = str(path)
        if self.path != ":memory:":
            Path(self.path).parent.mkdir(parents=True, exist_ok=True)
        self.conn = duckdb.connect(self.path)
        for statement in STATEMENTS:
            self.conn.execute(statement)

    def close(self) -> None:
        self.conn.close()

    def insert_fo(self, effective: date, rows: list[FoRow], *, sha256: str, size_bytes: int, retrieval_ts: datetime, available_ts: datetime) -> str:
        current = self.conn.execute("SELECT sha256 FROM ingest_files WHERE kind='fo' AND effective_date=? AND is_current", [effective]).fetchone()
        if current and current[0] == sha256:
            return "unchanged"
        outcome = "revised" if current else "inserted"
        self.conn.execute("BEGIN")
        try:
            if current:
                self.conn.execute("UPDATE ingest_files SET is_current=false WHERE kind='fo' AND effective_date=?", [effective])
                self.conn.execute("DELETE FROM fo_daily WHERE effective_date=?", [effective])
            retrieval, available = to_utc_naive(retrieval_ts), to_utc_naive(available_ts)
            columns = {name: [getattr(row, name) for row in rows] for name in FO_COLUMNS if name != "row_number"}
            table = pa.table({
                "effective_date": pa.array([effective] * len(rows), pa.date32()),
                "available_ts": pa.array([available] * len(rows), pa.timestamp("us")),
                "retrieval_ts": pa.array([retrieval] * len(rows), pa.timestamp("us")),
                "source_sha256": pa.array([sha256] * len(rows), pa.string()),
                "row_number": pa.array(list(range(len(rows))), pa.int32()),
                **{name: values for name, values in columns.items()},
            })
            self.conn.register("batch", table)
            self.conn.execute("INSERT INTO fo_daily SELECT * FROM batch")
            self.conn.unregister("batch")
            self.conn.execute("INSERT INTO ingest_files VALUES ('fo', ?, ?, ?, ?, ?, true)", [effective, sha256, size_bytes, retrieval, available])
            self.conn.execute("COMMIT")
        except Exception:
            self.conn.execute("ROLLBACK")
            raise
        return outcome

    def fo_dates(self) -> list[date]:
        return [r[0] for r in self.conn.execute("SELECT DISTINCT effective_date FROM fo_daily ORDER BY 1").fetchall()]

    def _content_hash(self) -> tuple[str, dict]:
        files = self.conn.execute("SELECT kind, effective_date, sha256 FROM ingest_files WHERE is_current ORDER BY kind, effective_date").fetchall()
        digest = hashlib.sha256("\n".join(f"{k}:{d.isoformat()}:{s}" for k, d, s in files).encode()).hexdigest()
        return digest, {"files": len(files)}

    def record_version(self, label: str, now: datetime) -> str:
        digest, counts = self._content_hash()
        count = self.conn.execute("SELECT count(*) FROM dataset_versions").fetchone()[0]
        version_id = f"v{count + 1:04d}-{digest[:12]}"
        self.conn.execute("INSERT INTO dataset_versions VALUES (?, ?, ?, ?, ?)", [version_id, to_utc_naive(now), label, digest, json.dumps(counts)])
        return digest

    def versions(self) -> list[dict]:
        cursor = self.conn.execute("SELECT version_id, created_ts, label, content_hash FROM dataset_versions ORDER BY version_id")
        return [dict(zip(["version_id", "created_ts", "label", "content_hash"], row)) for row in cursor.fetchall()]
```

```python
from __future__ import annotations

from datetime import date, datetime

from ..ist import require_aware, to_utc_naive
from ..nse.rows import FoRow
from .store import FO_COLUMNS, Store


class PointInTimeReader:
    """Every read takes an explicit as-of time and never returns data that was not yet available at that time."""

    def __init__(self, store: Store):
        self.store = store

    def fo_rows(self, effective: date, as_of: datetime) -> list[FoRow] | None:
        cutoff = to_utc_naive(require_aware(as_of))
        cursor = self.store.conn.execute(
            f"SELECT {', '.join(FO_COLUMNS[1:])} FROM fo_daily WHERE effective_date=? AND available_ts<=? ORDER BY row_number", [effective, cutoff])
        data = cursor.fetchall()
        if not data:
            return None
        return [FoRow(*row[:16], int(row[16]), row[17], row[18]) for row in data]

    def available_dates(self, as_of: datetime) -> list[date]:
        cutoff = to_utc_naive(require_aware(as_of))
        return [r[0] for r in self.store.conn.execute("SELECT DISTINCT effective_date FROM fo_daily WHERE available_ts<=? ORDER BY 1", [cutoff]).fetchall()]

    def latest_available_date(self, as_of: datetime) -> date | None:
        dates = self.available_dates(as_of)
        return dates[-1] if dates else None
```

```python
from pathlib import Path


class CalendarNotVerified(RuntimeError):
    pass


@dataclass(frozen=True)
class CalendarDiscrepancy:
    date: date
    kind: str  # "trading_day_without_archive" | "archive_on_non_trading_day"


class TradingCalendar:
    def __init__(self, holidays: set[date], verified: bool):
        self.holidays = frozenset(holidays)
        self.verified = verified

    @classmethod
    def from_file(cls, path: Path | str, require_verified: bool = False) -> "TradingCalendar":
        data = json.loads(Path(path).read_text(encoding="utf-8"))
        if require_verified and not data.get("verified"):
            raise CalendarNotVerified(f"{path} is not marked verified; confirm it against the official NSE list first.")
        return cls({date.fromisoformat(h["date"]) for h in data["holidays"]}, bool(data.get("verified")))

    def is_trading_day(self, day: date) -> bool:
        return day.weekday() < 5 and day not in self.holidays

    def previous_trading_day(self, day: date) -> date:
        day -= timedelta(days=1)
        while not self.is_trading_day(day):
            day -= timedelta(days=1)
        return day

    def next_trading_day(self, day: date) -> date:
        day += timedelta(days=1)
        while not self.is_trading_day(day):
            day += timedelta(days=1)
        return day

    def add_trading_days(self, day: date, n: int) -> date:
        step = self.next_trading_day if n > 0 else self.previous_trading_day
        for _ in range(abs(n)):
            day = step(day)
        return day

    def trading_days(self, start: date, end: date) -> list[date]:
        days, day = [], start
        while day <= end:
            if self.is_trading_day(day):
                days.append(day)
            day += timedelta(days=1)
        return days

    def cross_check(self, archive_dates: set[date], start: date, end: date) -> list[CalendarDiscrepancy]:
        out: list[CalendarDiscrepancy] = []
        day = start
        while day <= end:
            trading, has_file = self.is_trading_day(day), day in archive_dates
            if trading and not has_file:
                out.append(CalendarDiscrepancy(day, "trading_day_without_archive"))
            elif has_file and not trading:
                out.append(CalendarDiscrepancy(day, "archive_on_non_trading_day"))
            day += timedelta(days=1)
        return out
```

```python
from __future__ import annotations

import calendar
from dataclasses import dataclass
from datetime import date, timedelta
from typing import Callable

from .nse.rows import FoRow

ReportSource = Callable[[date], "list[FoRow] | None"]


@dataclass(frozen=True)
class CycleSnapshot:
    expiry_date: str
    first_eligible_trading_day: str
    entry_timestamp: str
    previous_trading_day: str
    t1_trading_day: str
    ranking_rows: tuple[FoRow, ...]


@dataclass(frozen=True)
class Contract:
    strike: float
    option_type: str
    fyers_symbol: str


@dataclass(frozen=True)
class RankedStock:
    ticker: str
    liquidity_metric: float
    lot_size: int | None
    contracts: tuple[Contract, ...]
    rank: int


def _first_report_between(report_on: ReportSource, start: date, end: date, descending: bool = False):
    days, day = [], start
    while day <= end:
        days.append(day)
        day += timedelta(days=1)
    if descending:
        days.reverse()
    for day in days:
        rows = report_on(day)
        if rows:
            return day, rows
    return None


def _expiry_for_month(report_on: ReportSource, year: int, month: int, today: date) -> str | None:
    month_end = date(year, month, calendar.monthrange(year, month)[1])
    probe_end = date(year, month, min(10, month_end.day))
    report = _first_report_between(report_on, date(year, month, 1), probe_end)
    if not report:
        return None
    prefix = f"{year:04d}-{month:02d}"
    expiries = sorted({r.expiry_date for r in report[1] if r.instrument_type == "STO" and r.option_type and r.expiry_date.startswith(prefix)})
    expiry = expiries[-1] if expiries else None
    if not expiry or expiry >= today.isoformat() or expiry > month_end.isoformat():
        return None
    return expiry


def discover_completed_monthly_cycles(report_on: ReportSource, today: date, count: int = 6) -> list[CycleSnapshot]:
    expiries: list[str] = []
    offset = 0
    while len(expiries) < count + 1 and offset < 18:
        total = today.year * 12 + (today.month - 1) - offset
        expiry = _expiry_for_month(report_on, total // 12, total % 12 + 1, today)
        if expiry:
            expiries.append(expiry)
        offset += 1
    if len(expiries) < count + 1:
        raise ValueError(f"Only {max(0, len(expiries) - 1)} completed monthly cycles could be reconstructed; {count} are required.")
    ordered = sorted(expiries)
    cycles: list[CycleSnapshot] = []
    for expiry in ordered[-count:]:
        previous_expiry = date.fromisoformat(ordered[ordered.index(expiry) - 1])
        expiry_day = date.fromisoformat(expiry)
        entry = _first_report_between(report_on, previous_expiry + timedelta(days=1), previous_expiry + timedelta(days=10))
        anchor = entry[0] if entry else previous_expiry
        previous = _first_report_between(report_on, anchor - timedelta(days=10), anchor - timedelta(days=1), True)
        t1 = _first_report_between(report_on, expiry_day - timedelta(days=10), expiry_day - timedelta(days=1), True)
        if not entry or not previous or not t1:
            raise ValueError(f"Trading-day boundaries could not be reconstructed for expiry {expiry}.")
        cycles.append(CycleSnapshot(expiry, entry[0].isoformat(), f"{entry[0].isoformat()}T09:20:00+05:30", previous[0].isoformat(), t1[0].isoformat(), tuple(previous[1])))
    return sorted(cycles, key=lambda c: c.expiry_date, reverse=True)


def rank_historical_universe(cycle: CycleSnapshot, limit: int = 50) -> list[RankedStock]:
    eligible: dict[str, list[FoRow]] = {}
    for row in cycle.ranking_rows:
        if row.instrument_type != "STO" or row.expiry_date != cycle.expiry_date or not row.option_type:
            continue
        eligible.setdefault(row.ticker, []).append(row)
    entries = []
    for ticker, option_rows in eligible.items():
        metric = sum(r.traded_value for r in cycle.ranking_rows if r.ticker == ticker)
        lot = next((r.lot_size for r in option_rows if r.lot_size > 0), None)
        contracts = tuple(Contract(r.strike, r.option_type, f"NSE:{r.instrument_name}") for r in option_rows if r.instrument_name and r.strike > 0)
        entries.append((ticker, metric, lot, contracts))
    entries.sort(key=lambda e: (-e[1], e[0]))
    return [RankedStock(t, m, lot, c, i + 1) for i, (t, m, lot, c) in enumerate(entries[:limit])]
```

```python
from dataclasses import dataclass

from .nse.rows import FoRow


@dataclass(frozen=True)
class UniverseEntry:
    ticker: str
    lot_size: int


def fno_universe_on(rows: list[FoRow]) -> list[UniverseEntry]:
    """Stocks that have both stock futures and stock options in the day's report, with the lot size of their earliest futures expiry."""
    futures: dict[str, tuple[str, int]] = {}
    options: set[str] = set()
    for row in rows:
        if row.instrument_type == "STF" and row.lot_size > 0:
            best = futures.get(row.ticker)
            if best is None or row.expiry_date < best[0]:
                futures[row.ticker] = (row.expiry_date, row.lot_size)
        elif row.instrument_type == "STO":
            options.add(row.ticker)
    return sorted((UniverseEntry(t, lot) for t, (_, lot) in futures.items() if t in options), key=lambda e: e.ticker)
```

```python
from __future__ import annotations

import csv
import io
from dataclasses import dataclass
from datetime import date

SUPPORTED = {"SPLIT", "BONUS", "OTHER"}


@dataclass(frozen=True)
class CorporateAction:
    ticker: str
    ex_date: date
    action_type: str
    a: float
    b: float
    source: str
    verified: bool


@dataclass(frozen=True)
class AdjustmentResult:
    factor: float
    unverified_count: int


def load_corporate_actions_csv(text: str) -> list[CorporateAction]:
    actions = []
    for number, row in enumerate(csv.DictReader(io.StringIO(text)), start=2):
        try:
            ex_date = date.fromisoformat(row["ex_date"].strip())
        except ValueError as error:
            raise ValueError(f"line {number}: invalid ex_date {row['ex_date']!r}") from error
        action_type = row["action_type"].strip().upper()
        if action_type not in SUPPORTED:
            raise ValueError(f"line {number}: unsupported action_type {action_type!r}")
        actions.append(CorporateAction(row["ticker"].strip().upper(), ex_date, action_type, float(row["a"] or 0), float(row["b"] or 0),
                                       row.get("source", "").strip(), row["verified"].strip().lower() == "true"))
    return actions


def adjustment_factor(actions: list[CorporateAction], ticker: str, session: date) -> AdjustmentResult:
    """Multiply a close of `session` by `factor` to express it in today's terms."""
    factor, unverified = 1.0, 0
    for action in actions:
        if action.ticker != ticker.upper() or action.ex_date <= session or action.action_type == "OTHER":
            continue
        factor *= (action.b / action.a) if action.action_type == "SPLIT" else (action.a / (action.a + action.b))
        unverified += 0 if action.verified else 1
    return AdjustmentResult(factor, unverified)
```

```python
from __future__ import annotations

from dataclasses import dataclass

from .nse.rows import FoRow


@dataclass(frozen=True)
class IntegrityIssue:
    severity: str  # "ERROR" | "WARN"
    code: str
    detail: str


def check_fo_rows(rows: list[FoRow]) -> list[IntegrityIssue]:
    issues: list[IntegrityIssue] = []
    seen: set[str] = set()
    futures_with_volume = [r for r in rows if r.instrument_type == "STF" and r.traded_volume > 0]
    if futures_with_volume and all(r.open_interest == 0 and r.change_in_open_interest == 0 for r in futures_with_volume):
        issues.append(IntegrityIssue("WARN", "FUTURES_WITHOUT_OPEN_INTEREST", "No traded futures row carries open interest."))
    for row in rows:
        name = row.instrument_name
        if name in seen:
            issues.append(IntegrityIssue("ERROR", "DUPLICATE_CONTRACT", name))
        seen.add(name)
        if row.high < row.low:
            issues.append(IntegrityIssue("ERROR", "HIGH_BELOW_LOW", name))
        if row.traded_volume > 0 and not (row.low <= row.close <= row.high):
            issues.append(IntegrityIssue("ERROR", "CLOSE_OUTSIDE_RANGE", name))
        if row.traded_volume > 0 and row.close <= 0:
            issues.append(IntegrityIssue("ERROR", "TRADED_WITHOUT_PRICE", name))
        if row.instrument_type in ("STF", "STO") and row.lot_size <= 0:
            issues.append(IntegrityIssue("ERROR", "MISSING_LOT_SIZE", name))
        if row.instrument_type in ("STF", "STO") and row.expiry_date < row.trading_date:
            issues.append(IntegrityIssue("ERROR", "EXPIRED_CONTRACT", name))
    return issues
```

```python
from __future__ import annotations

from datetime import datetime

from .ist import to_utc_naive
from .store.store import Store


class IncidentLog:
    def __init__(self, store: Store):
        self.conn = store.conn

    def record_once(self, kind: str, message: str, now: datetime) -> bool:
        if self.conn.execute("SELECT 1 FROM incidents WHERE kind=? AND resolved_ts IS NULL", [kind]).fetchone():
            return False
        next_id = self.conn.execute("SELECT coalesce(max(id), 0) + 1 FROM incidents").fetchone()[0]
        self.conn.execute("INSERT INTO incidents VALUES (?, ?, ?, ?, NULL)", [next_id, kind, message, to_utc_naive(now)])
        return True

    def resolve(self, kind: str, now: datetime) -> bool:
        if not self.conn.execute("SELECT 1 FROM incidents WHERE kind=? AND resolved_ts IS NULL", [kind]).fetchone():
            return False
        self.conn.execute("UPDATE incidents SET resolved_ts=? WHERE kind=? AND resolved_ts IS NULL", [to_utc_naive(now), kind])
        return True

    def _rows(self, where: str) -> list[dict]:
        cursor = self.conn.execute(f"SELECT id, kind, message, opened_ts, resolved_ts FROM incidents {where} ORDER BY id")
        return [dict(zip(["id", "kind", "message", "opened_ts", "resolved_ts"], row)) for row in cursor.fetchall()]

    def open_incidents(self) -> list[dict]:
        return self._rows("WHERE resolved_ts IS NULL")

    def all(self) -> list[dict]:
        return self._rows("")
```

```python
from __future__ import annotations

import argparse
from dataclasses import dataclass, field
from datetime import date, datetime, timedelta, timezone
from pathlib import Path

from .calendar import TradingCalendar
from .incidents import IncidentLog
from .integrity import check_fo_rows
from .nse.archive import NseArchiveClient
from .store.store import Store


@dataclass
class IngestReport:
    inserted: list[date] = field(default_factory=list)
    unchanged: list[date] = field(default_factory=list)
    revised: list[date] = field(default_factory=list)
    gaps: list[date] = field(default_factory=list)
    errors: list[str] = field(default_factory=list)


def ingest_range(client: NseArchiveClient, store: Store, calendar: TradingCalendar, incidents: IncidentLog, start: date, end: date, now: datetime) -> IngestReport:
    report, day = IngestReport(), start
    while day <= end:
        if calendar.is_trading_day(day):
            fetched = client.fetch_fo(day)
            if fetched is None:
                report.gaps.append(day)
                incidents.record_once("DATA_GAP", f"No F&O archive for trading day {day.isoformat()}.", now)
            else:
                problems = [i for i in check_fo_rows(fetched.rows) if i.severity == "ERROR"]
                if problems:
                    detail = f"{day.isoformat()}: " + "; ".join(f"{p.code} {p.detail}" for p in problems[:5])
                    report.errors.append(detail)
                    incidents.record_once("INTEGRITY_ERROR", detail, now)
                else:
                    outcome = store.insert_fo(day, fetched.rows, sha256=fetched.sha256, size_bytes=fetched.size_bytes, retrieval_ts=fetched.retrieved_at, available_ts=fetched.available_at)
                    getattr(report, outcome).append(day)
        day += timedelta(days=1)
    if not report.gaps:
        incidents.resolve("DATA_GAP", now)
    if not report.errors:
        incidents.resolve("INTEGRITY_ERROR", now)
    store.record_version(f"ingest {start.isoformat()}..{end.isoformat()}", now)
    return report


def main(argv: list[str] | None = None) -> None:
    parser = argparse.ArgumentParser(description="Download NSE F&O daily archives into the local store (paper/data only).")
    parser.add_argument("--from", dest="start", required=True)
    parser.add_argument("--to", dest="end", required=True)
    parser.add_argument("--data-dir", default=str(Path(__file__).resolve().parents[2] / "data"))
    parser.add_argument("--holidays", default=str(Path(__file__).resolve().parents[3] / "reference" / "nse_holidays.json"))
    args = parser.parse_args(argv)
    from .safety import assert_paper_only

    assert_paper_only()
    data_dir = Path(args.data_dir)
    store = Store(data_dir / "fno.duckdb")
    calendar = TradingCalendar.from_file(args.holidays, require_verified=True)
    now = datetime.now(timezone.utc)
    report = ingest_range(NseArchiveClient(data_dir / "raw"), store, calendar, IncidentLog(store), date.fromisoformat(args.start), date.fromisoformat(args.end), now)
    print(f"inserted={len(report.inserted)} unchanged={len(report.unchanged)} revised={len(report.revised)} gaps={len(report.gaps)} errors={len(report.errors)}")


if __name__ == "__main__":
    main()
```

```python
from __future__ import annotations

import json
import os
from dataclasses import dataclass
from datetime import datetime, timedelta, timezone
from enum import Enum
from pathlib import Path
from typing import Mapping

EXPIRING_WINDOW = timedelta(minutes=30)
DEFAULT_MAX_AGE_HOURS = 8.0  # conservative assumption until the Phase 0 FYERS audit records the real lifetime


class TokenStatus(Enum):
    OK = "OK"
    EXPIRING = "EXPIRING"
    EXPIRED = "EXPIRED"
    MISSING = "MISSING"
    REJECTED = "REJECTED"


class TokenPathInsideRepo(RuntimeError):
    pass


@dataclass(frozen=True)
class TokenRecord:
    client_id: str
    access_token: str
    obtained_at: datetime
    expires_at: datetime
    rejected_at: datetime | None = None

    def __repr__(self) -> str:  # never print the token
        return f"TokenRecord(client_id={self.client_id!r}, access_token='***', expires_at={self.expires_at.isoformat()})"


def token_path_from_env(env: Mapping[str, str] | None = None) -> Path:
    env = os.environ if env is None else env
    return Path(env.get("FNO_ENGINE_TOKEN_FILE") or Path.home() / ".fno-engine" / "fyers_token.json")


def _utc_now() -> datetime:
    return datetime.now(timezone.utc)


class TokenStore:
    def __init__(self, path: Path | str, repo_root: Path | None = None):
        self.path = Path(path).resolve()
        root = (repo_root or Path(__file__).resolve().parents[4]).resolve()
        if self.path == root or root in self.path.parents:
            raise TokenPathInsideRepo(f"The token file must live outside the repository ({root}).")

    def load(self) -> TokenRecord | None:
        try:
            data = json.loads(self.path.read_text(encoding="utf-8"))
            return TokenRecord(data["client_id"], data["access_token"], datetime.fromisoformat(data["obtained_at"]), datetime.fromisoformat(data["expires_at"]),
                               datetime.fromisoformat(data["rejected_at"]) if data.get("rejected_at") else None)
        except (OSError, ValueError, KeyError, TypeError):
            return None

    def _write(self, record: TokenRecord) -> None:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        payload = {"client_id": record.client_id, "access_token": record.access_token, "obtained_at": record.obtained_at.isoformat(),
                   "expires_at": record.expires_at.isoformat(), "rejected_at": record.rejected_at.isoformat() if record.rejected_at else None}
        self.path.write_text(json.dumps(payload), encoding="utf-8")
        try:
            os.chmod(self.path, 0o600)  # effective on POSIX; Windows ACLs are not enforced here (documented limitation)
        except OSError:
            pass

    def save(self, client_id: str, access_token: str, obtained_at: datetime, max_age_hours: float = DEFAULT_MAX_AGE_HOURS) -> TokenRecord:
        record = TokenRecord(client_id, access_token, obtained_at, obtained_at + timedelta(hours=max_age_hours))
        self._write(record)
        return record

    def mark_rejected(self, now: datetime) -> None:
        record = self.load()
        if record:
            self._write(TokenRecord(record.client_id, record.access_token, record.obtained_at, record.expires_at, now))

    def status(self, now: datetime) -> TokenStatus:
        record = self.load()
        if record is None:
            return TokenStatus.MISSING
        if record.rejected_at is not None and record.rejected_at >= record.obtained_at:
            return TokenStatus.REJECTED
        if now >= record.expires_at:
            return TokenStatus.EXPIRED
        return TokenStatus.EXPIRING if record.expires_at - now <= EXPIRING_WINDOW else TokenStatus.OK

    def expiry_note(self, now: datetime) -> str | None:
        record = self.load()
        return None if record is None else f"expires {record.expires_at.isoformat()}"
```

```python
from .auth.token_store import TokenStatus, TokenStore

KIND = "FYERS_TOKEN_UNAVAILABLE"


@dataclass(frozen=True)
class GateDecision:
    allow_entries: bool
    reason: str | None


def entry_gate(status: TokenStatus) -> GateDecision:
    if status in (TokenStatus.MISSING, TokenStatus.EXPIRED, TokenStatus.REJECTED):
        return GateDecision(False, f"FYERS token {status.value.lower()}: new entries are blocked until a fresh login.")
    return GateDecision(True, "FYERS token expiring soon." if status is TokenStatus.EXPIRING else None)


class TokenMonitor:
    def __init__(self, tokens: TokenStore, incidents: IncidentLog):
        self.tokens, self.incidents = tokens, incidents

    def check(self, now: datetime) -> GateDecision:
        status = self.tokens.status(now)
        decision = entry_gate(status)
        if decision.allow_entries:
            self.incidents.resolve(KIND, now)
        else:
            self.incidents.record_once(KIND, decision.reason or status.value, now)
        return decision
```

```python
from datetime import date, datetime, timezone
```

```python
def _utc_now() -> datetime:
    return datetime.now(timezone.utc)


def create_app(store: Store, tokens: TokenStore, now: Callable[[], datetime] = _utc_now) -> FastAPI:
    app = FastAPI(title="fno-engine (read-only)", docs_url=None, redoc_url=None)
    reader = PointInTimeReader(store)

    def universe_for(day: date):
        rows = reader.fo_rows(day, now())
        if rows is None:
            raise HTTPException(404, f"No published F&O data for {day.isoformat()}.")
        return {"date": day.isoformat(), "source": "engine", "availableAsOf": now().isoformat(),
                "entries": [{"ticker": e.ticker, "lotSize": e.lot_size} for e in fno_universe_on(rows)]}

    @app.get("/health")
    def health():
        return {"status": "ok", "time": now().isoformat()}

    @app.get("/token/status")
    def token_status():
        status = tokens.status(now())
        decision = entry_gate(status)
        return {"status": status.value, "allowEntries": decision.allow_entries, "reason": decision.reason, "note": tokens.expiry_note(now())}

    @app.get("/incidents")
    def incidents():
        log = IncidentLog(store)
        return {"open": [_json(i) for i in log.open_incidents()], "all": [_json(i) for i in log.all()]}

    @app.get("/universe/latest")
    def universe_latest():
        latest = reader.latest_available_date(now())
        if latest is None:
            raise HTTPException(404, "No published F&O data is stored yet.")
        return universe_for(latest)

    @app.get("/universe/{day}")
    def universe_on(day: str):
        try:
            parsed = date.fromisoformat(day)
        except ValueError as error:
            raise HTTPException(400, "day must be YYYY-MM-DD or 'latest'.") from error
        return universe_for(parsed)

    return app


def _json(row: dict) -> dict:
    return {k: (v.isoformat() if isinstance(v, datetime) else v) for k, v in row.items()}
```

```ts
    const response = await fetchImpl(`${baseUrl}/universe/${encodeURIComponent(day)}`, { cache: 'no-store', signal: controller.signal });
    if (!response.ok) return null;
    const body = await response.json() as { date?: unknown; entries?: unknown };
    if (typeof body.date !== 'string' || !Array.isArray(body.entries)) return null;
    const entries = body.entries.filter((e): e is { ticker: string; lotSize: number | null } => typeof (e as { ticker?: unknown }).ticker === 'string');
    return { date: body.date, entries };
  } catch {
    return null;
  } finally {
    clearTimeout(timer);
  }
}
```

```ts
import type { EngineUniverse } from '@/lib/engine-client';
import type { MarketStock } from '@/lib/market-snapshot';

export type ResolvedUniverse = { stocks: MarketStock[]; source: 'engine' | 'static'; date: string | null; note: string };

export function resolveUniverse(snapshot: MarketStock[], engine: EngineUniverse | null): ResolvedUniverse {
  if (!engine || engine.entries.length === 0) {
    return { stocks: snapshot, source: 'static', date: null, note: 'Engine unavailable: showing the static universe list (dated 2026-08-31).' };
  }
  const known = new Map(snapshot.map((stock) => [stock.ticker, stock]));
  const stocks = engine.entries.map(({ ticker }): MarketStock => known.get(ticker) ?? { symbol: `NSE:${ticker}-EQ`, ticker, name: ticker, price: 0, change: 0, changePct: 0, previousClose: 0 });
  return { stocks, source: 'engine', date: engine.date, note: `F&O universe from the engine, as of ${engine.date}.` };
}
```
